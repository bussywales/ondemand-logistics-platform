# Public Proof Assets

This directory is reserved for reviewed, staging-safe ShipWright product proof visuals used by the public site, demo pack, and investor materials.

Rules:
- use staging-safe or generic data only
- do not include real customer, courier, merchant, investor, or personal data
- do not include secrets, bearer tokens, API keys, webhooks, cookies, or private URLs
- do not include local proof JSON artifacts
- crop or redact emails, names, phone numbers, exact addresses, payment provider identifiers, and internal-only IDs unless explicitly approved for the demo
- do not use fake customer logos, fake production metrics, or fabricated claims
- review screenshots before they are referenced on the public site

Expected filenames:
- `release-readiness-ready.png`
- `validation-evidence.png`

The landing page is asset-ready: it will use reviewed files that exist here and fall back to CSS-native product visuals when files are absent.
