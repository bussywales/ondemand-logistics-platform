# Proof Archive

This folder stores timestamped release and proof artifacts created by the staging verification scripts.

Current artifact types:
- `paid-delivery-<timestamp>.json`
- `release-verify-<timestamp>.json`

The artifacts are operational evidence, not hand-written notes. They should be generated by:

```bash
pnpm release:verify-staging
pnpm proof:staging-paid-delivery
```

Interpretation rules:
- `PASS` means the script observed the expected live condition.
- `FAIL` means the release should not be treated as healthy.
- `SKIP` means the check was intentionally not executed, usually because a token or provider signal was unavailable.

Do not edit proof artifacts manually. Generate a fresh artifact instead.
